# Specification Amendment A-003: Anchored Cells Identity Alignment (I3 Site-Keyed Noise) and Extension Isolation

**Amendment ID:** A-003  
**Date:** 2026-10-24  
**Status:** PROPOSED (Pending Owner Approval)  
**Affects:** docs/spec/ (Part 5.5 Conflict Rules, Part 6.2 Anchored Cells)  
**Ground Truth Dependencies:** Decision D-012, D-014, Specification Amendment A-001, A-002, Phase 2b Empirical Findings

---

## 1. Summary of Architectural Realignment

The Aegis Master Specification (Part 5.5) originally specified the requirements for an Anchored Cell (e.g., online banking, sensitive SaaS, corporate credentials) as:
> `Anchored Cell (banking): S minimum S2; I minimum I2; extensions off.`

Amendment A-003 amends this specification in two critical ways:
1. **Identity Axis Realignment (I3 instead of I2):** Anchored Cells use **$I3$ (site-keyed noise via FPP)** rather than $I2$ (RFP uniform spoofing).
2. **Extension Isolation via Dedicated Instance:** Because WebExtensions in the Gecko engine are instance-wide and cannot be restricted per container, extension isolation ("extensions off") is achieved via a dedicated **`banking`** preset instance.

---

## 2. Anti-Fraud & Usability Rationale for I3

Enforcing $I2$ (`privacy.resistFingerprinting: true`) for online banking introduces severe operational failures due to modern financial fraud-detection systems:

1. **Anti-Fraud Bot Heuristics:**
   - RFP forces the JavaScript timezone to UTC (`Atlantic/Reykjavik`), spoofs display geometry with letterboxing margins, quantizes timer precision, and sanitizes WebGL vendor/renderer strings to `"Mozilla"`.
   - Major retail banks, payment gateways (Stripe, Adyen, PayPal), and multi-factor authentication (2FA) platforms execute client-side risk telemetry to detect credential-stuffing bots and headless automation.
   - An artificial UTC timezone combined with a non-matching IP geo-location, quantized timers, and spoofed 1200×600 canvas dimensions is classified by risk engines as automated attack infrastructure, triggering continuous CAPTCHA loops, failed device registration, or automated account lockouts.

2. **The Security Advantage of I3 (FPP Site-Keyed Noise):**
   - Under $I3$ (`privacy.fingerprintingProtection: true`, D-012, A-002), the browser injects deterministic, origin-salted canvas perturbation (`EfficientCanvasRandomization`).
   - Third-party tracking scripts cannot link the user's banking activity to external browsing because canvas and graphics readbacks produce an origin-unique salt.
   - Concurrently, $I3$ preserves the user's authentic local timezone, natural display resolution, and hardware capabilities, ensuring legitimate first-party anti-fraud checks succeed without false-positive lockouts.

---

## 3. Extension Isolation Rationale (Dedicated Instance)

Part 5.5 requires "extensions off" for Anchored Cells.
- Empirical testing confirms that Gecko's WebExtension subsystem is process-global. All content scripts, background pages, and API hooks registered by active extensions execute across all tabs and containers (`userContextId`) within the running instance.
- Multi-Account Containers provide state and cookie partitioning, but **cannot restrict or disable extensions** for a specific tab.
- Allowing third-party extensions (e.g., translation tools, coupon finders, password managers) to inject scripts into banking DOM sessions exposes session tokens and keystrokes to potential extension supply-chain compromise.
- Therefore, to satisfy "extensions off", Anchored Cells run in a dedicated preset instance (**`banking`**) launched with `extensions.enabledScopes: 0` and an isolated profile directory (`profiles/aegis-banking/`).

### 4.2 Amendment to Part 6.2: Anchored Cells

**Amended Text:**
> - An Anchored Cell opens in the dedicated `banking` preset instance (`{S2, I3, N1}`) with extensions disabled instance-wide.
> - Surface enforces $S2$ (HTTPS-only mode locked, audio autoplay blocked, WebRTC ICE restricted to default interface).
> - Identity enforces $I3$ (FPP site-keyed noise with remote overrides locked false), preserving local timezone and display geometry to prevent anti-fraud false-positive account lockouts while isolating cross-site canvas linkability.
> - Saved credentials fill **only** in the Anchored Cell and only on declared anchored domains.
> - Navigating to a non-anchored domain opens a different preset instance and displays a clear notice.
